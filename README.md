# 🌌 Celestial

> A premium, high-performance desktop shell experience for Arch Linux and Hyprland.

![Preview](shell/wallpapers/astronauta-frente-a-saturno_3840x2160_xtrafondos.com.jpg)

Celestial is a unified environment that bridges the gap between your desktop, login screen, and system theme. Built on top of **Quickshell** and **Caelestia**, it provides a seamless visual flow powered by dynamic thining and high-end animations.

---

## ✨ Features

- 🚀 **One-Command Install**: Get up and running in minutes.
- 🎨 **Dynamic Theming**: Integrated with `Wallust` for system-wide color harmony.
- 🌘 **SDDM Sync**: Automatic synchronization of wallpaper and theme to your login screen.
- 🛸 **Caelestia Shell**: A modern, high-performance shell built with QML and C++.
- 🌠 **Curated Aesthetic**: Pre-configured for a stunning out-of-the-box experience.

---

## 🛠️ Installation

Ready to go? Run this single command on your Arch Linux machine:

```bash
git clone https://github.com/zarateaz/celestial.git && cd celestial && chmod +x install.sh && ./install.sh
```

### Prerequisites
- **Arch Linux** (or derivative like Garuda)
- **Hyprland** installed and running

---

## 📂 Repository Structure

- `shell/`: Core QML shell and C++ plugin.
- `configs/`: Pre-configured Hyprland and Waypaper settings.
- `scripts/`: System integration scripts (SDDM sync, wallpaper handling).
- `install.sh`: Automated system-wide installer.
